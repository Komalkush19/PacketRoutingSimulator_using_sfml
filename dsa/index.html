Dynamic Packet Routing Simulator

Graph + Dijkstra + Min-Heap + Dynamic Re-Routing

Load the demo network, then choose source and destination.

Algorithm

Dijkstra's Shortest Path

The network is a weighted graph. Routers are vertices, links are weighted edges, and the minimum-cost route is found using a min-heap priority queue.

Controls
